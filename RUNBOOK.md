# RUNBOOK

Everything runs from one Apple-silicon machine. Three environments only: the project venv,
the pinned LLVM Docker container, and a host Ollama daemon (the single host-level exception,
because Docker on macOS has no Metal access).

## 0. One-time setup

```bash
# Python (3.11) venv; requirements.lock.txt is the frozen set from a real install
python3.11 -m venv .venv && .venv/bin/pip install -r scripts/env/requirements.lock.txt && .venv/bin/pip install -e .

# Pinned LLVM 19.1.7 toolchain (mlir-opt, mlir-cpu-runner, llvm-tblgen, lli, clang), ~1 h cold build
docker compose -f scripts/env/docker-compose.yml build --build-arg BUILD_JOBS=10 --build-arg LINK_JOBS=3
docker compose -f scripts/env/docker-compose.yml up -d
export PATH="$PWD/scripts/env/bin:$PATH"     # docker-exec wrappers for the tools above
mlir-opt --version

# Models: resolve + download pinned revisions into the HF cache
.venv/bin/python scripts/env/pin_models.py      # writes scripts/env/models.lock.txt
```

Requires Docker Desktop with ≥ 32 GB allocated for the LLVM build. Gemma checkpoints are gated on
the Hub; accept the terms once and run `hf auth login` before `pin_models.py`.

## 1. Tests

```bash
.venv/bin/python -m pytest -q -m "not docker and not mlx and not ollama"   # fast subset (CI)
.venv/bin/python -m pytest -q                                              # everything (needs container + MLX)
```

## 2. Data

- `data/benchmarks/*.jsonl` — public NL→MLIR test sets (test-only; never used for training).
- `data/pools/*.jsonl` — frozen evaluation pools (`arith_func_200`, `linalg_125`), see `sci/data/pools.py`.
- `data/functional/references.json` — 30 hand-authored functional references.
- Training pool: generated by `sci/data/` (see `scripts/w02_build_pool.py`), disjoint from every file above.

## 3. Experiments

One runner per experiment under `scripts/wNN_*.py`, writing `results/wNN_<exp>/` (summary JSON + per-row
JSONL). Long runs: `caffeinate -dims .venv/bin/python scripts/... 2>&1 | tee logs/<name>.log`. macOS lowers
the priority of long MLX jobs after ~20–30 min; `sudo renice -n -5 -p <pid>` restores it.

## 4. Anonymity

`scripts/anon_check.sh` greps tracked files and history against a local blocklist and must pass before any
push or artifact build.
